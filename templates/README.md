## Template Format

Each template should:

- Be bilingual (English + Arabic) or exist in separate `en/` and `ar/` subdirectories
- Include a header with: purpose, applicable entity types, last reviewed date, and source references
- Use checkboxes (`- [ ]`) for action items
- Note which steps require professional assistance
- Include a disclaimer that requirements may change
